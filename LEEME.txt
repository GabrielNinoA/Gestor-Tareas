Electiva - PWA · UPTC

Qué es esto
-----------
Es el mismo Gestor de Tareas que construiste en los Bloques 1 (JavaScript) y
2 (TypeScript), ya cerrado: agregar, completar y eliminar tareas, con
persistencia en localStorage. Todavía NO es una PWA — no tiene manifest.json
ni Service Worker. Ese es justo el trabajo del Sub-bloque A (Sesiones 15-23):
partiendo de este mismo código, cada sesión le agrega una técnica de PWA.

Se entrega como punto de partida común para que todos trabajen las guías de
fundamentación sobre el mismo código, sin importar en qué quedó tu propia
versión durante los Bloques 1-2.

Cómo abrirlo
------------
Este proyecto usa módulos de JavaScript (export/import), así que el
navegador NO lo deja abrir con doble clic (protocolo file://) — hace falta
verlo desde un servidor local. Dos formas rápidas:

  1. VS Code + extensión "Live Server": clic derecho sobre index.html →
     "Open with Live Server".
  2. Terminal, parado en esta carpeta:
       python3 -m http.server 8080
     y abrir http://localhost:8080 en el navegador.

Estructura
----------
  index.html               interfaz + <script type="module">
  css/estilos.css           estilos
  tareas.js                 lógica: crearTarea, renderizarTarea, cargarTareas
  app.js                    punto de entrada: importa y arranca todo
  referencia-typescript/    la versión tipada (tareas.ts + tsconfig.json) tal
                             como se entregó al cierre del Bloque 2 — es solo
                             de referencia, la app corre con tareas.js.
